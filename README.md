## Stack

Python 3.10+ • NumPy • Pandas • Matplotlib • Seaborn • Scikit-Learn

## Run

    pip install numpy pandas matplotlib seaborn scikit-learn

Then run the task scripts in the repository, for example:

    python ml_task1_house_price.py
    python ml_task4_titanic.py
    python ml_task6_customer_seg.py
    python ml_task7_spam.py
    python ml_task8_diabetes.py

## Reported Results

The existing project documentation reports approximately 95% R² for house-price regression, 80% Titanic accuracy, 0.65 silhouette score for segmentation, 95% spam accuracy and 95% diabetes accuracy. These should be reproduced against the current code/data before being treated as benchmarks.
